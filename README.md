# Credit-card-fraud-detection
his repository implements a machine learning pipeline to detect fraudulent credit card transactions. The pipeline covers data exploration, preprocessing, feature engineering, model training, evaluation, and simple deployment examples.The goal is to provide a reproducible, well-documented example that demonstrates how to build a high-quality fraud-detection model using tabular transaction data.

Key features:

End-to-end pipeline: data → features → models → evaluation

Comparison of multiple models (Logistic Regression, Random Forest, XGBoost, etc.)

Handling class imbalance (SMOTE, class weights, threshold tuning)

Explainability: feature importances and SHAP visualization example

Notebook-driven exploration + modular scripts for production
